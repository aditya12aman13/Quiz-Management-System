# Quiz Management System

A comprehensive web-based Quiz Management System built with ASP.NET (C#). This platform provides an intuitive interface for administrators and educators to easily manage quizzes, courses, topics, and questions.

## Features
- **Admin Dashboard**: Centralized management area for administrators.
- **Course & Topic Management**: Add and manage educational courses and their respective topics.
- **Question Bank**: Easily add, edit, and organize quiz questions.
- **Reporting System**: Generate comprehensive reports on courses and questions to track progress and analyze data.
- **Secure Authentication**: Admin login and secure password management capabilities.

## Tech Stack
- **Frontend**: HTML, CSS, ASP.NET Web Forms
- **Backend**: C# (ASP.NET)
- **Database**: SQL Server (Schema provided in `database.sql`)
